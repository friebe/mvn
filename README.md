# MVN

Elastischer Schreibtisch-Copilot für Minimal Viable Movement.

Lokale PWA — kein Account, keine Cloud, nur LocalStorage.

## Entwickeln

```bash
npm install
npm run dev
```

## Bauen

```bash
npm run build
npm run preview
```

## Intervalle

| Mode | Sit | Stand | Reset |
|------|-----|-------|-------|
| High | 30 min | 5 min | 1 min |
| Lazy | 20 min | 3 min | 1 min |
